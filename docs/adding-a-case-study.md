# Adding a case study — collection checklist

For whoever gathers the material. **You do not need to touch the website to use this.** Collect the items below, hand them over, and the page gets built from them.

Every number here comes from the five case studies already live, so anything in range will look right beside them.

---

## The short version

| # | What | Notes |
|---|---|---|
| 1 | Project title | The game or campaign name |
| 2 | Client name | Exactly as they write it |
| 3 | Year | Four digits |
| 4 | Timeline | "8 Weeks", "2 Months" — however the team says it |
| 5 | Services | 1–4 of: Campaigns, Consulting, Finance, Legal |
| 6 | Project website + link text | Optional |
| 7 | Summary | 150–160 characters |
| 8 | **Hero image** | 16:9, min 1000×562 |
| 9 | **Three headline stats** | Number + what it measures |
| 10 | Stats graphic | Optional; numbers must match #9 |
| 11 | Challenge copy | 1–2 paragraphs |
| 12 | Solution copy | 3–4 paragraphs |

---

## 1–6. The facts

**Title** — the game or campaign name. Existing ones run 10–21 characters ("Warframe", "Legends of Lost Ark").

**Client** — the company, as they spell it. "Amazon Games", "2K Games", "Thunder Lotus".

**Year** — the campaign year, four digits.

**Timeline** — free text. Existing: "2 Months", "3 Weeks", "8 Weeks", "12 Weeks", "16 Weeks".

**Services** — pick 1–4 from exactly these four, spelled this way:

> **Campaigns · Consulting · Finance · Legal**

Anything else won't match the rest of the site. Most case studies use all four.

**Website** — the game or campaign's own page, if it has one, plus the words to make clickable. The existing five all phrase this differently — "Spiritfarer Website", "warframe.com", "Return to Aeternum Event" — so use whatever reads best.

---

## 7. Summary

One or two sentences on what the campaign achieved. This appears under the title **and is what Google shows in search results.**

**Aim for 150–160 characters.** Google truncates around there. The existing five run 189–293, which means several are being cut off mid-sentence in search — worth doing better on new ones.

> *"Still considered to be the gold standard of Twitch win-back campaigns, this collaboration with Amazon Games resulted in billions of minutes watched and a nearly 900% return on investment."* — 189 characters

---

## 8. Hero image ⚠️ most common problem

The key art. Used three ways: the case study page, the `/projects` card, and the homepage card.

| | |
|---|---|
| **Shape** | **16:9 landscape.** All five existing heroes are exactly this |
| **Minimum size** | 1000 × 562 |
| **Better** | 1600 × 900 or 2000 × 1125 |
| **File size** | **Aim under 500KB.** One existing hero is 1.9MB — avoidable |
| **Format** | JPG or PNG. JPG for photographic art, PNG for flat graphics |

**Send the largest clean version you have** at 16:9. The site generates its own smaller copies automatically — you never need to supply multiple sizes.

⚠️ **A square or portrait image will be cropped**, and it will not look like the others. If all you have is square, say so rather than sending it as-is.

**Also send a one-line description of what's in the picture** — "Key art showing a Viking warrior before a mountain range". That becomes the alt text, which is what screen readers read out and what search engines index. The old site had none of these, which is one of the things this rebuild fixed.

---

## 9. The three headline stats ⚠️ read this carefully

**Exactly three.** Not two, not four — the layout is built for three.

Each is a **number** and **what it measures**, supplied separately:

| Number | What it measures |
|---|---|
| `196,000` | Peak Viewership on Twitch |
| `1.9 Billion` | Minutes Watched on Twitch |
| `96,900` | Total Hours Streamed |

**Rules that keep them looking right:**

- **Number: keep it short**, 12 characters max. `9,000%`, `3.5 Billion`, `+7 Million`, `66,000+` all work. A long number wraps and breaks the layout.
- **Don't repeat the number in the description.** Write "Minutes Watched", not "1.9 Billion Minutes Watched" — the two are displayed together.
- **Description: 35 characters max.** Existing run 7–33.
- **Order matters** — they display in the order supplied. Lead with the most impressive.

**Pick stats that are comparable to the others.** The existing set is peak viewers, minutes watched, hours streamed, influencers activated, streams, broadcasters, return on investment. A stat nobody else reports invites the question "compared to what?".

---

## 10. Stats graphic — optional

The circular results infographic that sits beside the copy. Existing ones are **1403 × 1080** (roughly 4:3), 60–70KB PNG.

> ⚠️ **The numbers in this graphic MUST match the three stats you supplied above.**
>
> This is a live problem on the current site. Borderlands 3 says *9,000% Return on Investment* in the text and *9,051% ROI* in the graphic. Spiritfarer's text headlines *+7 Million* minutes while its graphic totals *10.6 million*. On client-facing portfolio work, a number that disagrees with itself invites exactly the wrong question.
>
> **Before sending: read the graphic, read the three stats, confirm they say the same thing.**

Also send a line describing what the graphic shows, including the figures — that becomes its alt text.

---

## 11. Challenge copy

What the client needed and why it was hard. **Set up the problem; don't solve it here** — that's the next section.

**1–2 paragraphs, 200–550 characters.** The existing five run 176–562.

---

## 12. Solution copy

What we did and what happened. This is the substance of the page.

**3–4 paragraphs, 600–2,000 characters.** Existing run 618–1,969, so there's real latitude.

A structure that works, drawn from the existing five:

1. **The approach** — the thinking, what made it different
2. **The execution** — what was actually done
3. **The outcome** — the result, with the headline figure

Put the biggest number in the **final** paragraph. It lands better as a payoff than as an opener, and it echoes the three stats rather than pre-empting them.

**Send plain text with blank lines between paragraphs.** No headings, no bullets — the layout supplies those. Bold is available if a figure needs emphasis mid-sentence.

---

## Before you hand it over

- [ ] Hero image is **16:9**, at least 1000×562, under ~500KB
- [ ] Hero image has a **written description** of what's in it
- [ ] **Exactly three** stats, each split into number + what it measures
- [ ] Number is **12 characters or fewer**; description is **35 or fewer**
- [ ] The description does **not** repeat the number
- [ ] **Stats graphic figures match the three stats** ← the one most often wrong
- [ ] Summary is **150–160 characters**
- [ ] Services use only: **Campaigns, Consulting, Finance, Legal**
- [ ] Challenge is 1–2 paragraphs, Solution is 3–4
- [ ] Client has **approved the numbers** for public use

---

## What happens next

The page is built from what you send, checked, and published. Four automatic checks run first: required information present, no broken links, images have descriptions, and the page works with a screen reader. **If anything fails, it doesn't publish** and the failure names the problem.

The web address comes from the project name — *Legends of Lost Ark* becomes `leviacore.com/project/legends-of-lost-ark`.

⚠️ **Once a case study is live its address can never change.** Renaming it breaks every link from Google, past emails and press coverage. Settle the name before it publishes.
