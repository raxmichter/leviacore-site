## Design Context

### Users
Brand-side marketers and producers at gaming publishers/studios evaluating an influencer marketing partner; secondary audiences include creators/influencers and talent managers researching the agency. Primary jobs: understand capability, trust the team, browse case studies, and make contact.

### Brand Personality
Confident, editorial, professional — gaming-industry credibility without "gamer aesthetic" clichés. Voice is direct and premium; the site should feel like a sharp agency book, not a SaaS landing page.

### Aesthetic Direction
Ink-on-warm-paper editorial system already shipped: Syne (display) + Satoshi (body) + Roboto Mono (UI meta), near-black `#191919` on warm off-white `#fdfbf5`, hairline dividers, asymmetric multi-column grids, case-study storytelling. Light mode only. **Anti-references:** generic AI/SaaS (cyan-on-dark, purple gradients, glassmorphism, Inter, hero-metric card grids), loud esports neon, and any redesign that breaks Webflow brand fidelity. Constraint: this is a Webflow→Astro fidelity migration — critique migration/responsive/UX execution, do not propose a new visual identity.

### Design Principles
1. **Fidelity over novelty** — match the established Leviathan Core brand; don't invent a new look.
2. **Editorial hierarchy** — type and hairline structure carry the brand; decoration is sparse and intentional.
3. **Case studies convert** — portfolio clarity and mobile readability matter as much as desktop polish.
4. **Contact must work** — the CTA path (form + response) is a production gate, not a nice-to-have.
5. **Responsive as adaptation** — narrow viewports should stack cleanly without crushing layout tracks or amputating content.
